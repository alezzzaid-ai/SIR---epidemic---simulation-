# SIR Epidemic Simulation with Machine Learning

This project simulates how an infectious disease spreads using the SIR (Susceptible–Infected–Recovered) model.  
I also added a simple machine learning model to explore how infection trends might look in the future.

## Features
- SIR epidemic simulation
- Data visualization using Matplotlib
- Linear regression for basic trend prediction
- Model evaluation using Mean Absolute Error (MAE)

## What I learned
- How to turn a mathematical model into code
- How infections change over time in a system
- How to visualize data clearly
- Basics of machine learning and prediction
- How to evaluate model accuracy

## How to run
pip install -r requirements.txt  
python epidemic_ml_project.py
